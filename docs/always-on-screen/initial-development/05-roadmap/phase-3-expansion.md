# Phase 3 — Expansion

Optional add-ons. **None of these block the summer deadline.**
Operator-paced, ship as desired.

## Prerequisites

- Phase 1A + 1B + 2 shipped.

## Candidates

### Branch standards expansion
- USSF (Space Force) — once a verified age-banded source is found.
- USN (Navy) — once verified.
- USA (Army ACFT) — once verified.
- Per-table `(preview)` labels remain until verified, then promote.

### Elite badges
- SEAL 4-mile threshold — ship with `popular-benchmark` label if
  no canonical NSW source confirms.
- Spetsnaz 3 km / 12 min — ship with `popular-benchmark` label.
- Spetsnaz 10 km +50 kg ≤ 1 h — deferred indefinitely; loaded
  carries are out of v1 design scope.

### Voice (TTS) cues
- Optional spoken updates in run-attempt mode (lap announcements).
- Optional pulse-cue voicing ("stand up, breathe twice").
- Off by default; settings-toggleable.

### Sleep self-report
- One-tap "to bed" / "awake" stamps.
- Feeds periodization recommendations (e.g. flag deload week if
  3+ short-sleep nights stack).

### Pomodoro-aware timing
- Heuristic detection of focus blocks (no taps + screen-on minutes).
- Pulse fire-time slides ±5 min to land on a likely break boundary.
- Off by default; opt-in.

### Insights extensions
- Time-to-respond distribution by hour-of-day.
- Anchor-event trend chart (rolling 30-d).
- Weekly absence heatmap.
- Per-element adherence trend.

### Pulse catalog v2
- Posture lane (eye break, neck reset, 20-20-20) refinements.
- Hydration cadence rules.
- Equipment-aware variants (jump rope present / absent).

## Out of scope (forever, in this design)

- GPS-based mile tracking.
- Heart-rate / wearable integration.
- Camera-based form analysis.
- Cloud sync, sharing, leaderboards.
- Auto-import from Strava / Apple Health.
- Multi-user shielding (single-operator desk).
