## Components (ACFT — ⚠ verify)

The ACFT is six events scored on a 600-point composite (100 per
event). Age- and sex-normed scoring tables.

| # | Event                            | Tests                          |
| - | -------------------------------- | ------------------------------ |
| 1 | **3-rep max deadlift** (MDL)     | Lower-body strength            |
| 2 | **Standing power throw** (SPT)   | Explosive power (10-lb ball)   |
| 3 | **Hand-release push-up — arm-extension** (HRP) | Upper endurance |
| 4 | **Sprint–drag–carry** (SDC)      | Anaerobic capacity             |
| 5 | **Plank** (PLK)                  | Core stability                 |
| 6 | **2-mile run**                   | Aerobic capacity               |

(The earlier "leg tuck" event was retired in favor of the plank.
⚠ verify still holds.)

## Integration into Always-On

Treated as a deferred anchor option. Until verified, selecting
"USA" in PFT mode (FR-8.1) shows a placeholder. Of the six events,
the ones that fit the operator's tablet-mediated dashboard (no gym
equipment required) are:

- HRP (push-ups)
- Plank
- 2-mile run

The MDL, SPT, and SDC require equipment/space that the desk-mediator
context does not provide; the dashboard surfaces them only as
"requires gym session" cards.
