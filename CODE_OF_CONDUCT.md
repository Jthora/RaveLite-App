# Code of conduct

This project is small and the standard is simple: **be decent.**

- Assume the person on the other end is trying.
- Criticise the code, the drill or the idea — never the person.
- No harassment, no slurs, no sexualised attention, no dragging in
  someone's identity as an argument.
- Fitness spaces attract judgement about bodies. Not here. Nobody's
  starting point is a punchline.
- Disagree in the open, decide, move on.

Maintainers may edit, hide or remove comments, commits, issues and pull
requests that do not fit, and may block accounts that keep at it.

To report something, open an issue. If it involves a maintainer or you
would rather not be public, open an issue saying only that you need a
private word.
